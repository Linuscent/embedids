<section class="home-band home-statement" aria-labelledby="overview" data-reveal>
<p class="statement">EmbedIDS is a lightweight Runtime Intrusion Detection SDK specifically designed for low-power embedded Internet of Things (IoT) devices. <span>Our open-source SDK provides AI-driven protection to address the critical security gap in constrained IoT environments.</span></p>
<div class="split">
<h2 id="overview">Overview</h2>
<p>EmbedIDS provides on-device, AI-driven protection tailored to resource-constrained embedded systems. By deploying compact anomaly-detection agents directly on devices, we enable real-time protection without relying on external connectivity or cloud dependencies.</p>
</div>
</section>

<section class="home-band home-why" aria-labelledby="why-embedids" data-reveal>
<h2 id="why-embedids">Why EmbedIDS?</h2>
<div class="why-grid">
<div class="why-col is-problem">
<p>The IoT security landscape faces unique challenges:</p>
<ul>
<li><strong>Resource constraints</strong> limit traditional security solutions</li>
<li><strong>Connectivity issues</strong> make cloud-dependent protection unreliable</li>
<li><strong>Scale requirements</strong> demand cost-effective deployment models</li>
<li><strong>Diverse hardware</strong> needs flexible, adaptable solutions</li>
</ul>
</div>
<div class="why-col is-answer">
<p>EmbedIDS addresses these challenges by providing:</p>
<ol>
<li><strong>On-device protection</strong> that works offline</li>
<li><strong>Lightweight implementation</strong> suitable for constrained devices</li>
<li><strong>Open-source model</strong> enabling rapid adoption and community collaboration</li>
<li><strong>AI-driven detection</strong> for sophisticated threat identification</li>
</ol>
</div>
</div>
</section>
